    Agent-Chat

    Fragen wie „Wie ist die Fraktionsverteilung in der 20. Wahlperiode?“ oder „Wer ist Friedrich Merz?“ — das LLM wählt die passenden Tools. Wählen Sie den Ausführungspfad: direktes Tool Calling oder MCP Client ↔ Server.

    Ausführungspfad

    Direkt ruft die Tool-Handler im Prozess auf. MCP nutzt einen MCP-Client, der dieselben Tools über das MCP-Protokoll am Server aufruft (in-process memory transport — auch auf Render zuverlässig).
